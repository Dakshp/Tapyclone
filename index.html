Quick add shortcut

A shortcut can ask for the amount, category and note, then log the expense on its own — Tappy flashes up, saves it and shows a confirmation, with nothing to tap.

Build it in the Shortcuts app:

  1. Ask for Input — Number — “How much did you spend?”
  2. Choose from Menu — one item per category, named exactly as in the list above (Food & Drink, Groceries, …)
  3. Ask for Input — Text — “Note (optional)”
  4. Text — paste the address above, replacing AMOUNT, CATEGORY and NOTE with those three answers
  5. Open URLs — pass it that Text

Then in iOS Settings assign it to Back Tap or the Lock Screen, or just say “Hey Siri, shortcut name”. Drop &save=1 from the address if you would rather check the entry before it is saved.
